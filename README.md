## Local Development

Requirements:

- Node.js 20+
- pnpm

Install dependencies:

```bash
pnpm install
```

Start development server:

```bash
pnpm dev
```

Open:

```text
http://localhost:3000
```

Production check:

```bash
pnpm lint
pnpm build
pnpm start
```
